# TF2 2008 PC - Launcher 0.3.1

Comprobación automática al abrir: primero actualiza el launcher y luego los archivos del juego.
No elimina archivos adicionales. Conserva configuraciones, mapas personalizados y archivos de usuario.
Antes de reemplazar archivos modificados guarda originales en la carpeta .tf2-update-backups dentro del juego.
Si el juego está abierto la actualización queda pendiente para el próximo inicio.
La instalación inicial se hace seleccionando una carpeta (no descarga 5 GB automáticamente si no está instalado).
El código y el manifiesto del launcher son independientes de los archivos del juego.
